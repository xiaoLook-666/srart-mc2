# MC 启动器

一个纯 Python 标准库实现的 Minecraft 启动器（无需安装任何第三方依赖）。

## 功能

- **版本列表**：从 Mojang 官方清单获取全部版本（正式版 / 快照），支持搜索与筛选
- **一键安装**：自动下载客户端、依赖库、原生库（自动解压）、资源文件（多线程加速），SHA1 校验
- **账号系统**：
  - 离线模式：任意昵称直接游玩单人世界
  - 微软正版登录：设备代码流（浏览器打开 microsoft.com/link 输验证码），支持刷新令牌，可进服务器
  - 自定义皮肤：离线账号可选本地 PNG 皮肤（内置皮肤服务器 + authlib-injector 自动注入，进世界后生效）
- **Java 管理**：
  - 自动检测系统已安装的 Java（注册表 / PATH / 常见目录）
  - 一键下载 Adoptium Java 运行时（8 / 17 / 21 / 25），官方源失败自动切换清华镜像
  - 按版本自动选择合适 Java（1.12.1 及更旧 → Java 8；1.18+ → 17；1.20.5+ → 21；26.x → 25）
- **启动**：支持新旧全部参数格式（1.5.2 远古版到最新版），实时游戏日志输出，可停止游戏
- **中文与联机**：游戏语言一键切换（默认简体中文）；填服务器地址可启动后直连
- **下载镜像**：官方源失败自动回退 BMCLAPI 国内镜像
- **设置**：游戏目录、内存、自定义分辨率、额外 JVM 参数、启动后自动关闭等
- **打包 exe**：`MC启动器.exe` 免安装直接运行（无需 Python）
- **陶瓦联机**：内置 Terracotta（陶瓦联机）客户端，房间码跨网络联机，无需注册

## 使用方法

### exe 版（推荐，免安装）

双击 `MC启动器.exe`。需要保证 exe 与 `_internal`、`tools`、`.minecraft` 等同目录（整个启动器文件夹一起拷贝即可）。

### 源码版

双击 `run.bat`，或命令行运行：

```
python launcher.py
```

首次使用建议：
1. 「账号」页 → 离线模式输入昵称（或微软登录）
2. 「启动」页 → 选中版本（默认 1.12.1）→ 点「启动」
3. 如果本机没有 Java，会提示并自动下载对应运行时（也可以到「设置」页手动下载）

### 陶瓦联机（跨网络好友联机）

1. 双方都打开启动器 → 点「陶瓦联机」按钮
2. 房主在陶瓦窗口「创建房间」，把房间码发给好友
3. 好友在陶瓦窗口输入房间码加入
4. 房主进游戏 → 单人世界 → ESC →「对局域网开放」
5. 好友进游戏 →「多人游戏」→ 双击「陶瓦联机大厅」进入

陶瓦联机由开源项目 [Terracotta](https://github.com/burningtnt/Terracotta) 提供（AGPL-3.0）。

### 命令行测试工具

```
python mc_core.py manifest                # 查看版本清单
python mc_core.py version 1.12.1          # 查看版本详情
python mc_core.py javas                   # 检测 Java
python mc_core.py download-jre 8          # 下载 Java 8 运行时
python mc_core.py install 1.12.1          # 安装版本
python mc_core.py dryrun 1.12.1           # 打印启动命令
```

## 目录结构

```
mc-launcher/
├── launcher.py        # 图形界面
├── mc_core.py         # 核心逻辑
├── run.bat            # 启动脚本
├── config.json        # 配置（自动生成）
├── runtime/           # 自动下载的 Java 运行时
├── natives/           # 解压后的原生库
├── versions/          # 版本 JSON 缓存
├── meta/              # 版本清单缓存
└── .minecraft/        # 默认游戏目录（版本 jar/库/资源/存档）
```

## 常见问题

- **离线模式能不能玩？** 可以玩单人世界；进服务器需要服务器开启离线模式（cracked）。
- **下载很慢？** 「设置」→ 下载源选「mirror」（镜像优先）；Java 运行时自动走清华镜像。
- **启动闪退？** 看启动器日志；确认内存分配合理（1.12.1 建议 2048 MB）。
- **正版登录提示未购买？** 该账号没有 Minecraft 正版授权，仅提示，仍可尝试启动。
